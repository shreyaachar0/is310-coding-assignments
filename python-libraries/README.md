Movie Data Collector

Project Overview:
For this assignment I made a Movie Data Collector that lets people type in and keep track of details, about their movies. The program takes three kinds of details: movie title, genre and year it came out. I made two versions of the project: a Python command-line interface and an HTML webpage.
Python CLI
The Python program uses the Rich library to show a table with example movies. People can type in their movie details look at what they entered and fix any errors before they finish adding the information. The program lets users add movies and keeps the information they have confirmed in a CSV file.

How to Run the Python Program:

1. Open Terminal and navigate to the python-libraries folder.

2. Install the required library using python3 -m pip install -r requirements.txt.

3. Run the program using python3 cli_data_entry.py.

4. Follow the instructions to enter your movie information.

HTML Interface

The HTML version lets users put in movie details using a webpage, not the Terminal. They can add movies check the information they entered and then download it as a CSV file.

How to Run the HTML Version: Open index.html in a web browser

Comparing the Two Interfaces

Both interfaces collect the information but they operate in different ways. The Python version is simple because it leads users through each question one at a time. However users need to use Terminal which could be hard for someone who has not used it before. The HTML version is easier to move because users can see all the fields all at once. It also lets users check their answers on the web page and get their data away. I made sure to keep the three fields, for both versions so the information would match. For checking the HTML version looks for missing fields and wrong release years. The Python version lets users make sure and fix their information.
