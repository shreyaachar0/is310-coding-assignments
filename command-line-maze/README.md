# Social Media Privacy Maze
Shreya Achar

Welcome to Shreya Achar's Social Media Privacy Maze! This maze is meant to see how our personal data moves through social media and to see how privacy can really affect users and society.

Your have to follow the clues until you find the final solution.

You start with entering the `entrance` directory and reading `start.txt`.

Commands that may help:

- `ls` — shows files and directories
- `cd folder_name` — enters a directory
- `cd ..` — goes back one directory
- `cat filename.txt` — reads a file
- `ls -a` — shows all files, including hidden files

Follow each clue to figure out where to go next!!! Good luck!!!!
