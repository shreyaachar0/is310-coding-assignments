National Parks Visits - Exploring and Visualizing Culture Homework

Overview: 
For this assignment, I used Pandas to explore national park visitation data and Altair to create a bar chart that is interactive. I looked at the 10 most visited national parks in 2024 to better understand how visits between parks differ.

How to Run:
1. Install the required libraries using pip install pandas altair jupyter.
2. Open national_park_visits.ipynb in VS Code.
3. Run all the cells in the correct order.
4. Hover over the chart to see the number of visits for each park.
